# 🧶 كروشيه أمل — Crochet Amal

متجر إلكتروني بسيط وأنيق لبيع قطع الكروشيه اليدوية:

- **صفحة هبوط (متجر)** بتصميم عربي RTL دافئ، فلاتر أقسام، سلة، وصفحة تفاصيل لكل منتج.
- **الطلبات تصل عبر واتساب** برسالة جاهزة تحتوي المنتجات والكميات والمجموع.
- **لوحة تحكم للمشرفة** لرفع المنتجات بالصور، تعديلها، حذفها، وتغيير إعدادات المتجر.
- **مربوط بـ Firebase** (Firestore + Authentication + Storage) — **وضع حقيقي فقط**، كل ما يراه الزبناء يأتي من قاعدة بياناتك.

---

## 🚀 التشغيل السريع

```bash
npm run dev
# أو
node server.js
```

ثم افتح:

| الصفحة | الرابط |
| --- | --- |
| المتجر | http://localhost:3000/index.html |
| لوحة التحكم | http://localhost:3000/admin.html |

> يمكن أيضًا فتح `index.html` مباشرة، لكن يُفضّل استخدام خادم محلي (مطلوب لـ Firebase).

**للدخول إلى لوحة التحكم** استخدمي البريد وكلمة المرور اللذين تنشئينهما في **Firebase ← Authentication ← Users**.
لن يعمل الموقع قبل إتمام خطوات الإعداد أدناه (Firestore + Storage + قواعد الأمان).

## 🔗 ربط Firebase (خطوة بخطوة)

### 1) إنشاء المشروع

1. اذهبي إلى [console.firebase.google.com](https://console.firebase.google.com) واضغطي **Add project**.
2. اختاري اسمًا مثل `crochet-amal` وأكملي الإنشاء.

### 2) تفعيل تسجيل الدخول

1. من القائمة: **Build → Authentication → Get started**.
2. تبويب **Sign-in method** ← فعّلي **Email/Password**.
3. تبويب **Users** ← **Add user** ← أدخلي بريد المشرفة وكلمة مرور قوية.
   هذه هي البيانات التي ستُستخدم للدخول إلى `admin.html`.

### 3) إنشاء قاعدة البيانات

1. **Build → Firestore Database → Create database**.
2. اختاري **Production mode** ثم منطقة قريبة (مثل `europe-west1`).

### 4) تفعيل تخزين الصور

1. **Build → Storage → Get started**.
2. اسمحي بالوصول بعد إعداد القواعد في الخطوة 6.

### 5) نسخ إعدادات الويب

**Project settings (⚙️) → Your apps → Web app (`</>`)** ← سجّلي التطبيق وانسخي القيم إلى:
`js/firebase-config.js`

الملف **`js/firebase-config.js`** مضبوط مسبقًا على مشروعك الحقيقي:

```js
window.FIREBASE_CONFIG = {
  apiKey: "AIzaSyDn3HX…",
  authDomain: "amale-crochet.firebaseapp.com",
  projectId: "amale-crochet",
  storageBucket: "amale-crochet.firebasestorage.app",
  messagingSenderId: "1029434187104",
  appId: "1:1029434187104:web:8ff1c2bf2a2b048ae51205",
};
```

> 💡 **ملاحظة أمنية:** هذه القيم ليست أسرارًا (مصمّمة لتكون عامة في تطبيقات الويب). الحماية الحقيقية تأتي من **قواعد Firestore/Storage** وقصر الكتابة على المستخدم المسجّل.

### 6) نشر قواعد الأمان

من [Firebase Console](https://console.firebase.google.com):

- **Firestore Database → Rules**: انسخي محتوى `firebase/firestore.rules` ثم **Publish**.
- **Storage → Rules**: انسخي محتوى `firebase/storage.rules` ثم **Publish**.

أو عبر Firebase CLI:

```bash
npm i -g firebase-tools
firebase login
firebase deploy --only firestore:rules,storage
```

### 7) (اختياري) النشر على Firebase Hosting

```bash
firebase init hosting     # public directory: .   |   Single-page app: No
firebase deploy --only hosting
```

أضيفي نطاق الموقع إلى **Authentication → Settings → Authorized domains** حتى يعمل تسجيل الدخول.

## 🛒 كيف تصل الطلبات عبر واتساب؟

1. الزبونة تضيف القطع إلى السلة.
2. تكتب اسمها ومدينتها (اختياريًا ملاحظات عن اللون أو المقاس).
3. تضغط **إتمام الطلب عبر واتساب** → يُفتح واتساب برسالة جاهزة، مثل:

```
سلام أمل 👋
بغيت نطلب من متجر كروشيه أمل:

• 2 × حقيبة كتف بالوردة الكروشيه — 640 د.م
• 1 × أرنوبة أميجورومي «لولو» — 180 د.م

المجموع: 820 د.م
الاسم: سلمى
المدينة: الدار البيضاء
ملاحظات: اللون البيج من فضلك

شكرًا! 🌸
```

**مهم:** رقم الواتساب يُضبط من **لوحة التحكم → إعدادات المتجر** (بصيغة دولية بلا `+`، مثال `212612345678`).
كل روابط «واتساب» في الصفحة تستخدم هذا الرقم.

## 🧑‍🎨 استخدام لوحة التحكم

| الإجراء | الطريقة |
| --- | --- |
| إضافة منتج | «إضافة منتج» ← املئي الاسم، القسم، السعر، الوصف ← اسحبي صورة أو ضعي رابطها ← حفظ |
| تعديل منتج | أيقونة ✏️ في قائمة المنتجات |
| إخفاء/إظهار | أيقونة 👁️ (تتحول القطعة إلى «غير متوفر» في المتجر) |
| حذف | أيقونة 🗑️ (تأكيد مطلوب) |
| منتج مميّز | مفتاح «منتج مميّز» ← يظهر أولًا في المتجر مع شارة |
| إعدادات التواصل | رقم واتساب، إنستغرام، فيسبوك، البريد، شريط الإعلان العلوي |

الصور تُضغط تلقائيًا (حد أقصى 1100px، JPEG) قبل الرفع لتسريع الموقع وتقليل الحجم.

## ✅ قائمة التحقق قبل فتح المتجر للزبناء

| # | الخطوة | المكان |
| --- | --- | --- |
| 1 | تفعيل **Email/Password** | Firebase ← Authentication ← Sign-in method |
| 2 | إنشاء مستخدمة المشرفة (بريد + كلمة مرور) | Firebase ← Authentication ← Users |
| 3 | إنشاء **Firestore Database** (Production mode) | Firebase ← Build ← Firestore Database |
| 4 | تفعيل **Storage** | Firebase ← Build ← Storage |
| 5 | نشر قواعد الأمان | Firestore ← Rules وStorage ← Rules (من مجلد `firebase/`) |
| 6 | ضبط رقم واتساب | لوحة التحكم ← إعدادات المتجر |
| 7 | إضافة أول منتج (أو استيراد منتجات البداية) | لوحة التحكم ← المنتجات |
| 8 | إضافة نطاق الموقع | Firebase ← Authentication ← Settings ← Authorized domains |

> بدون الخطوات 1–5 ستظهر رسالة «تعذّر تحميل المنتجات» أو لن يعمل تسجيل الدخول — وهذا سلوك مقصود: الموقع لا يعرض بيانات وهمية أبدًا.

### أول تشغيل (5 دقائق)
1. افتحي `admin.html` ← سجّلي الدخول بحساب Firebase.
2. في تبويب **المنتجات** سيظهر زر **«استيراد منتجات البداية»** — يضيف ٦ قطع إلى Firestore لتراها في المتجر فورًا، ثم عدّلي الصور والأسعار.
3. اضغطي **إعدادات المتجر** وضعي رقم واتساب الحقيقي (بصيغة `2126XXXXXXXX`).
4. افتحي `index.html` — المتجر الآن حقيقي وكل زبونة ترى منتجاتك وتطلب عبر واتساب.

## 🌐 النشر

الموقع **ثابت بالكامل** (HTML/CSS/JS) ويمكن نشره على:

- **GitHub Pages**: Settings → Pages → Branch `main` → `/ (root)`.
- **Netlify / Vercel**: اسحبي المجلد كما هو، لا حاجة لأمر بناء.
- **Firebase Hosting**: كما في الخطوة 7.

بعد النشر، أضيفي النطاق إلى **Authorized domains** في Firebase Authentication.

## 🎨 تخصيص الهوية

كل الألوان والخطوط في أعلى `css/style.css`:

```css
:root {
  --cream: #fbf7f1;      /* خلفية دافئة */
  --terracotta: #bd6f56; /* اللون الأساسي */
  --sage: #8b9b7d;       /* لون ثانوي */
  --ink: #38302a;        /* النصوص */
}
```

- رقم الواتساب الافتراضي والنصوص التعريفية: `js/data.js`.
- الأقسام: `window.CA_CATEGORIES` في `js/data.js` (وتُضاف تلقائيًا أي أقسام جديدة من المنتجات).
- الصور التجريبية في `assets/img/` — استبدليها بصور القطع الحقيقية من لوحة التحكم.

## ✅ ملاحظات تقنية

- بدون أي تبعيات أو خطوة بناء — JavaScript عادي (ES Modules للـ Firebase SDK).
- واجهة عربية RTL متجاوبة (جوال/تابلت/سطح مكتب) مع مراعاة `prefers-reduced-motion`.
- السلة والمفضلة محفوظتان محليًا للزبونة.
- البيانات الحساسة (كلمة المرور) لا تُخزَّن في الكود؛ المصادقة تتم عبر Firebase Auth.

## 🧯 حل المشاكل الشائعة

| الرسالة / المشكلة | السبب والحل |
| --- | --- |
| «تعذّر تحميل المنتجات» | Firestore غير مُنشأ أو القواعد تمنع القراءة ← نفّذي الخطوات 3 و5 |
| «البريد أو كلمة المرور غير صحيحة» | لا يوجد مستخدم بهذا البريد ← أنشئيه في Authentication ← Users |

| «غير مصرّح برفع الصور» | Storage غير مفعّل أو قواعده غير منشورة |
| «هذا النطاق غير مسموح» | أضيفي نطاقك في Authorized domains |
| المنتجات لا تظهر للزبناء بعد الإضافة | تأكدي أن المنتج «متوفر»، ثم حدّثي الصفحة (Firestore يحدّث لحظيًا عند إعادة التحميل) |
